# How to download and Run it locally
If you want to boot it up and try out the app on your own computer, just copy and paste these commands into your terminal start from #1:

```bash
# 1. Clone this repo to your computer
git clone https://github.com/ynagpal009/HACK_CLUB-PROJECT

# 2. Navigate straight into the dowloaded repo folder
cd HACK_CLUB-PROJECT

# 3. Boot up the main login portal application
python3 main.py
```
