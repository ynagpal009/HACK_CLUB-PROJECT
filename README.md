# Sports Equipment Inventory Management System 

A local Python desktop app built with Tkinter and SQLite to help schools or clubs track gear, manage stock, 
and see who is borrowing equipment without messy spreadsheets.

# How I Built It
Built with **Python 3**:
* UI: Tkinter and TTK with custom styles for a cleaner look.
* Database: SQLite3 for real-time inventory and log tracking.
* Reporting: Uses Python's csv module to export data summaries.

# How to download and Run it locally
If you want to boot it up and try out the app on your own computer, just copy and paste these commands into your terminal start from #1:

```bash
# 1. Clone this repo to your computer
git clone https://github.com/ynagpal009/HACK_CLUB-PROJECT

# 2. Navigate straight into the dowloaded repo folder
cd HACK_CLUB-PROJECT

# 3. Boot up the main login portal application
python3 main.py
```
